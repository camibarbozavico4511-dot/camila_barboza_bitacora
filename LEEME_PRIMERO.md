# Mi bitácora — Introducción a la Ciencia de Datos

Esta carpeta está separada del repositorio de la profesora. Abrila en VS Code con **File > Open Folder**.

## Estado real de la reconstrucción

- Clases 1–9: carpetas y material fuente de cada clase organizados para reconstruir la bitácora. **No se presentan los ejemplos de clase como ejercicios propios resueltos**.
- Clase 3: prácticos A y B con las **soluciones originales publicadas por la profesora**.
- Clase 10: consignas, análisis y CSV, **sin resolver**, para hacer en clase.

No se pudo recuperar el cuaderno personal perdido. Para completar fielmente las demás respuestas hacen falta las consignas concretas y resolverlas una por una; los materiales de varias clases son demostraciones, no hojas de ejercicios.

## Para no volver a perderla

Guardá esta carpeta en iCloud Drive o hacé copias periódicas. Si usás GitHub, creá un repositorio **privado** para tus trabajos.

## Lenguajes

Hay clases con Python y R. Para archivos `.R` necesitás R; instalar pandas no sirve para ejecutarlos.
